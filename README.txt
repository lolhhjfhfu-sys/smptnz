TNZ SMP — ГОТОВЫЙ САЙТ

Файлы:
- index.html — главная страница
- style.css — оформление
- script.js — интерактивность
- logo.jpg — логотип TNZ SMP
- background.png — фон сайта
- TNZ-SMP-Launcher.exe — лаунчер для Windows

Для запуска:
1. Загрузите все файлы в одну папку на ваш хостинг.
2. Главной страницей должен быть index.html.
3. Не переименовывайте TNZ-SMP-Launcher.exe, если хотите, чтобы кнопка скачивания работала без изменения HTML.
